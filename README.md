## 📖 About Quiz Hub

**Quiz Hub** is a modern, interactive web application designed to help Sri Lankan students master science concepts through engaging quizzes, flashcards, and gamified learning experiences. Built as a Progressive Web App (PWA), it works seamlessly on any device and supports full offline functionality.

The app features a beautiful dark-mode interface with **9 stunning themes**, **Sinhala language support**, and a comprehensive learning ecosystem with achievements, leaderboards, and daily challenges.

### Why Quiz Hub?

- 📱 **PWA App** - Install on any device, works like a native app
- 📡 **Offline Ready** - Study anywhere, even without internet
- 🇱🇰 **Sinhala Support** - Built for Sri Lankan students
- 🎮 **Gamified Learning** - Makes studying fun and engaging
- 🎨 **9 Themes** - Choose your favorite color scheme

## ✨ Key Features

### Core Features

| Feature | Description |
|---------|-------------|
| 📚 **Study Mode** | Learn at your own pace with detailed explanations |
| 🎮 **Game Mode** | Challenge yourself with 3 lives, 20s timer, and power-ups |
| 🃏 **Flashcard Mode** | Interactive flip cards for quick revision |
| 🏆 **Leaderboard** | Compete with others and track your ranking |
| 🏅 **Achievements** | Unlock 11 unique achievements as you progress |
| 📅 **Daily Challenges** | Complete daily targets to earn bonus points |

### Advanced Features

| Feature | Description |
|---------|-------------|
| 💾 **Local Storage** | All progress saved automatically |
| 🔊 **Sound Effects** | Audio feedback for correct/wrong answers |
| 🎉 **Celebrations** | Confetti and effects for 100% scores |
| 💡 **Hints System** | Get help when stuck (Study mode) |
| 🎯 **Power-ups** | 50/50 and Skip options (Game mode) |
| ⌨️ **Keyboard Shortcuts** | Fast navigation without mouse |

## 🛠️ Tech Stack

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Grid, Flexbox, Animations
- **Vanilla JavaScript** - No frameworks, pure JS
- **Font Awesome 6** - Icon library
- **Google Fonts** - Space Grotesk, Inter, Noto Sans Sinhala

### PWA Features
- **Service Workers** - Offline caching
- **Web App Manifest** - Install to home screen
- **Local Storage** - Persistent data
- **Session Storage** - Session data

### APIs Used
- **Web Audio API** - Sound effects
- **Fullscreen API** - Immersive mode
- **Clipboard API** - Share functionality
